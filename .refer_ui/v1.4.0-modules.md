### 侧边栏四种形态

| 形态 | 触发条件 | 宽度 | 特点 |
|------|----------|------|------|
| 展开侧边栏 | 桌面端 > 800px | 230px | 图标+文字+角标，按分类分组 |
| 折叠侧边栏 | 桌面端 ≤ 800px 自动 | 60px | 仅图标+Tooltip |

| 移动端底部导航 | 移动端 ≤ 768px | 全宽 | Material 3 NavigationBar，显示前 5 项 |

## 【学习】分组（8 个模块）

### 1. 课程 `/courses`
无 TabBar、无 Drawer、无下拉刷新。**列表/课表双视图切换**：列表模式含搜索栏 + `ListView.separated` 课程卡片（ListTile），每行含课程名、教师、类型、状态，右侧可快捷跳转查老师/下载/成绩。课表模式含学年/学期下拉选择器，渲染 `TimetableGrid` 自定义组件。AppBar 有缓存新鲜度徽标和刷新按钮。

```
features/courses/module.dart
features/courses/screens/courses_screen.dart
features/courses/widgets/timetable_grid.dart
```

### 2. 开课情况 `/course-offerings`
无 TabBar、无 Drawer、无下拉刷新。**列表+搜索栏布局**。顶部含学年/学期选择器（PopupMenuButton）和搜索输入框。课程按类型分组展示（必修/选修等），每组有分类标题和课程卡片。核心交互为学年学期切换、本地关键词搜索（课程名/教师/地点/代码）、手动刷新。

```
features/zdbk/module.dart
features/zdbk/screens/course_offerings_screen.dart
```

### 3. 培养方案 `/training-plans`
无 TabBar、无 Drawer、无下拉刷新。**列表+多级筛选布局**。顶部有年级→学院→专业三个筛选 Chip（点击弹出 AlertDialog 选择器），下方为培养方案卡片列表。核心交互为三级联动筛选，点击方案卡片查看 PDF 详情（通过 PdfPreviewWidget 内嵌渲染）、手动刷新数据。

```
features/zdbk/screens/training_plan_screen.dart
```

### 4. 待办 `/todo`
无 TabBar、无 Drawer、无下拉刷新。**卡片列表+筛选栏**。顶部含两行筛选栏：平台筛选（ChoiceChip：全部/学在浙大/PTA），过期开关（FilterChip）+排序切换（ActionChip）。列表区为自定义 `_TodoCard` 卡片，左侧彩色优先条+任务标题+课程名+来源标签+截止日期。支持过期任务自动隐藏（可点击显示）、按平台/日期筛选。

```
features/todo/module.dart
features/todo/screens/todo_screen.dart
```

### 5. 计划管理 `/plan`
**有 Drawer**（左侧滑出，`PlanDrawer` 组件）、无 TabBar、无下拉刷新。**表单+可折叠卡片列表**。Drawer 内切换/创建/删除计划。主区域为 `ListView` 滚动表单：计划名称 TF、序语/得失总结/规划要点三个 `ExpansionTile` 含 Markdown 编辑框、规划大纲 `ExpansionTile` 含任务列表（添加/编辑/切换/删除）+ `BottomSheet` 导入面板（含 3 个 Tab：待办/考试/课表批量勾选导入）、规划方案 `ExpansionTile` 含 `PlanTable` 时间表网格。

```
features/plan/module.dart
features/plan/screens/plan_screen.dart
features/plan/widgets/plan_drawer.dart
features/plan/widgets/plan_table.dart
features/plan/widgets/plan_task_card.dart
features/plan/widgets/add_edit_task_dialog.dart
```

### 6. 成绩 `/scores`
无 TabBar、无 Drawer、无下拉刷新。**仪表盘+搜索栏+图表列表混合**。顶部 `SegmentedButton` 切换策略（保研/出国），4 个 GPA 卡片（五分制/四分制4.3/四分制4.0/百分制）各含 `LinearProgressIndicator`。中部含 `fl_chart` 趋势折线图和成绩分布柱状图。底部固定学期下拉+搜索框，成绩列表为 `CustomScrollView` 混合 SliverList（头部图表）+ SliverList（卡片列表）。

```
features/scores/module.dart
features/scores/screens/scores_screen.dart
```

### 7. 考试 `/exams`
无 TabBar、无 Drawer、无下拉刷新。**列表/日历双视图切换**。列表模式按紧急程度分组：7天内(红色)→30天内→后续→已结束，每组含分组标题+考试卡片（自定义 `ExamCard`）。日历模式含自定义渲染的月视图网格（手绘 7×N 格，自适应宽度），选中日期下方展开当日考试列表。AppBar 含视图切换按钮和新鲜度徽标。

```

features/exams/screens/exams_screen.dart
features/exams/widgets/exam_card.dart
```

### 8. 下载 `/downloads`
无 TabBar、无 Drawer、无下拉刷新。**下拉选择器+文件列表**。顶部课程下拉选择框（DropdownButtonFormField），下方 `ListView.builder` 展示文件卡片（ListTile），每项含下载状态图标（等待/下载中圆形进度/完成✅/失败❌）、文件名、大小和下载进度。下载完成后可打开文件所在文件夹。支持下载中实时进度更新。

```

features/downloads/screens/downloads_screen.dart
```

## 通用渲染模式总结

| 模式 | 使用模块数 | 典型特征 |
|------|-----------|----------|

### 交互特点
- **无 TabBar**：全部 28 个模块均不使用 TabBar 做页面级导航（仅智云课堂播放器在移动端用 TabBar 切 PPT/字幕）
- **有 Drawer**：仅 2 个模块（AI 助手 / 计划管理），用于会话/计划列表
- **有下拉刷新**：仅 2 个模块（教务通知 / 数据状态）
- **统一三态**：所有数据模块均支持 loading/error/data 三态渲染
- **新鲜度徽标**：9 个模块的 AppBar 含 `FreshnessBadge` 缓存时间提示
