### Bug 修复清单

1. **marketplace manifest 解析失败** — `preset` 字段误写为 String（应为 Map），导致 `ModuleDescriptor.fromJson` 抛异常被静默吞掉 → 改为 `"type": "fullscreen"`
2. **插件市场"暂无本地插件"** — `MarketplaceSlot.initState` 硬编码相对路径 `'plugins'`，运行目录为 `evg-base/` 扫到空目录 → 改为 `ConsumerStatefulWidget` + `ref.read(pluginsDirProvider)` 三级回退注入绝对路径
3. **SlotDispatch ref 编译错误** — `ref.read()` 在 `StatelessWidget` 中不可用 → 改用 `ProviderScope.containerOf(context, listen: false).read()`
4. **全部插件目录被误判为隐藏** — `entity.path.contains(r'\.')` 在 Windows 路径 `D:\..\plugins\ai-planner` 中匹配到 `\..\` → 改为 `p.basename(entity.path).startsWith('.')` + `p.normalize()`
5. **plugin_preloader.dart 5 个编译失败** — 缺失 `import 'dart:io';`（`Directory` 未定义）→ 已修复
6. **Python Runner agent manifest 缺 type 字段** — `plugins/python-runner/agent/manifest.json` 无 `"type"` 字段，导致 `ModuleDescriptor.fromJson` 抛 `FormatException`，市场扫描跳过
7. **其他未被记录的 bug**
