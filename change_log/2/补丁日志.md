# 补丁日志

## 2026-07-07

### 1. 新增 Agent 工具选项面板

用户可在聊天界面的工具栏点击「工具」芯片，弹出面板查看所有已注册工具，通过 Switch 开关启用或禁用。核心工具（read/write_global_memory、read_file、write_file）标有 ★ 星标及「核心」标签，禁用时弹出警告提示受影响的功能。工具启用状态持久化到 SharedPreferences，重启后保留。

### 2. 多级深度思考参数

从原先的二元开关改为五档选择（关/低/中/高/最强），上游通过 `reasoningEffortProvider` 控制 DeepSeek API 的 `reasoning_effort` 参数，UI 在工具栏以弹出菜单形式供用户选择。**注意**：当前 UI 仅完成芯片展示，未完全对接上游参数（芯片点击后弹出菜单可选项但视觉反馈尚未完善）。

### 3. Skill 生成方式扩展（仅上游）

新增 `SkillGenerator` 类（`skill_generator.dart`），支持调用 LLM 根据用户自然语言需求自动生成 Skill 的 Markdown 内容（含 frontmatter 和 body）。原有手动编辑 Skill 的表单仍保留，待下游 UI 对接后可提供「手写」与「AI 生成」两种方式。

### 4. 优化部分渲染

- TabBar 指示线加粗至 3px 并增加圆角，支持 emoji 前缀与文字分离渲染
- Slot 卡片增加圆角 10px、微阴影（boxShadow），增强视觉层次
- 侧边栏导航项增加 hover / splash 颜色反馈，提升桌面端点击手感
- 嵌入式输入栏增加工具选项入口图标

### 5. 解决 flutter test 卡死

根因：`sprint2_test.dart` 中 SettingsView 的两个测试调用了 `SharedPreferences.getInstance()` 但未预先调用 `SharedPreferences.setMockInitialValues({})`，导致在测试环境中永久挂起。修复：在 `main()` 顶部加入 `SharedPreferences.setMockInitialValues({})`。同时删除了编译错误的调试文件 `_debug_hang_test.dart`。
