## 原理

### 1. 中游核心定位

中游是**声明层**——插件开发者不写 Dart UI 代码，只填写 JSON 声明文件，平台根据声明自动生成 UI。中游的核心哲学："声明即应用"。

### 2. 插件的组成结构

```
plugins/<name>/
├── module/
│   ├── manifest.json        ← 模块声明（必填 type: "module"）
│   └── <name>.exe            ← 后端进程（Python 打包或任意语言）
├── agent/
│   ├── manifest.json         ← Agent 工具声明（name/description/schema/argMode）
│   └── <name>.exe            ← 可执行文件
├── config/config.json        ← 设置项声明
├── theme/theme.json          ← 主题定义
├── data/manifest.json        ← 数据源声明
└── skill/*.md                ← Skill 定义文件
```

### 3. Manifest.json 驱动范式

Module 的 `manifest.json` 是整个中游的核心：

```json
{
  "type": "module",
  "schemaVersion": "2.0",
  "id": "my-module",
  "name": "我的模块",
  "route": "/my-module",
  "renderMode": "dart",
  "process": {
    "exe": "module/my-module.exe",
    "protocol": "http",
    "scope": "module",
    "autoStart": true,
    "autoRestart": false
  },
  "pages": [
    {
      "id": "page1",
      "title": "页面一",
      "layout": {
        "type": "composite",
        "preset": "sidebar-left",
        "slots": {
          "left": { "component": {...} },
          "main": { "component": {...} }
        }
      }
    }
  ],
  "actions": [{ "id": "export", "label": "导出", "process": {...} }]
}
```

### 4. 四级 .exe 进程生命周期

.exe 与**组件**挂钩（不是与模块挂钩）：

| 层级 | 声明位置 | 生命周期 |
|------|---------|---------|
| ① 模块级 | `ModuleDescriptor.process` | 模块加载 → 卸载 |
| ② 页面级 | `PageDescriptor.globalProcess` | 页面激活 → 切走 |
| ③ 栏位/组件级 | `ComponentConfig.process` | 栏可见 → 隐藏 |
| ④ 动作级 | `ActionButtonDescriptor.process` | 按钮触发 → 完成即退出 |

### 5. Agent 工具的三种 argMode

- **stdin**：JSON 写入 stdin → 读取 stdout
- **args (flag)**：`--key value` 格式
- **args (positional)**：按 order 顺序排列 value
- **args (json)**：`--args=<json>` 整体传递

### 6. V2 渲染模式

- `renderMode: "dart"` → Flutter Widget 渲染（ModuleDispatch → CompositeView/EditorView/DefaultView）
- `renderMode: "html"` → WebView 内嵌 HTML 渲染（HtmlRenderView）

## 效果

- **插件热加载**：放入 `plugins/` 目录即自动注册，无需重启宿主
- **语言无关**：任何语言只要能输出 HTTP 或 stdout 即可
- **manifest.json 即 UI**：53 种组件类型（chat/table/code/spreadsheet/document/form/calendar/lottery 等）通过 JSON 声明即可生成
- **进程管理**：ModuleLoader 自动管理 .exe 生命周期（启动→PORT 解析→health check→优雅关闭）
- **能力发现**：discoverCapabilities 扫描子目录自动判定六维能力
