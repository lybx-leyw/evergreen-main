# .internal — AI 内部认知文档

> 本文件夹由 AI（Claude）维护，供 AI 在每次 `git pull` 后快速重建对项目的认知。
> 人类开发者无需关注此文件夹内容——它是 AI 的"项目心智模型缓存"。

## 文件说明

| 文件 | 用途 |
|------|------|
| `01-接轨文件.md` | AI 对项目全局的认知总结，每次 pull 后重写 |
| `02-上游说明.md` | core/ 服务层的结构、原理、效果 |
| `03-中游说明.md` | plugins/ 插件层的结构、原理、效果 |
| `04-下游说明.md` | renderer/ 渲染层的结构、原理、效果 |
| `05-变更内容简述.md` | 仅记录最近一次 git pull 的变更内容 |

## 维护规则

1. **每次 `git pull` 后**，AI 必须立即重写本文件夹中所有 5 个文件
2. 01-04 文件更新认知理解，05 文件更新为本次变更的简述（不累计历史）
3. 写完所有文件后更新本 README 的最后更新时间和 commit hash
4. 不要删除这个文件夹或其中的任何文件
