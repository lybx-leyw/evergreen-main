## 三、核心基础设施变更（7 文件）

### 3.1 Agent 风暴抑制器重构（`agent.dart`，+93 行）

- **StormBreaker 改版**：从「失败+重复成功」双阈值压制 →「仅连续失败」压制
  - 移除 `successThreshold` 参数和 `_repeatSuccessCounts`
  - 成功调用立即重置失败计数、取消抑制
  - 切换工具（不同签名）重置计数
- **工具执行流程调整**：StormBreaker 检查从「工具执行前（读工具）」移到「工具执行后（按结果判断）」
  - 只对写工具生效；连续失败 ≥3 次触发抑制
  - 抑制事件带 `error` 字段发射，让模型感知被阻止

### 3.2 Config HTTP Server 增强（`config_http_server.dart`，+106 行）

- **端点从 8 扩至 9**：新增 `POST /config/settings`（批量写入，body `{key, value}`）
- **动态设置注册**：`registerSetting(key, label)` / `unregisterSetting(key)` — 运行时注入配置项无需 config.json 声明
- `GET /config/settings` 列表合并动态注册项
- `POST` 写入时自动注册为动态设置项
- 端点编号重排：4→批量写入, 5→路径写入, 6-9→权限/源

### 3.3 Module Descriptor 增强（`module_descriptor.dart`，+34 行）

- **`PageDescriptor.hideTab`**：封面页等不需页面导航时设为 true
- **`LayoutPreset.fromJson`**：支持嵌套 `regions` 键（manifest 规范格式），兼容直接写在 preset 层级的区域
- **`SpreadsheetOptions._toIntCount`**：动态值安全转 int（List→length, num→toInt, 其他→fallback）

### 3.4 Main 入口增强（`main.dart`，+49 行）

- **Web 平台守卫**：`kIsWeb` 时提前退出，显示「不支持 Web/Chrome」提示
- **media_kit 初始化**：libmpv 视频播放（Windows/macOS/Linux）
- **WebView2 CDP 远程调试**：`--remote-debugging-port=9222`，供爬虫模块通过 CDP Network 域捕获 HTTP 请求
- **桌面窗口条件**：改为 `!kIsWeb && Platform.is*` 守卫

### 3.5 依赖更新（`pubspec.yaml`，+12 行）

| 新增依赖 | 用途 |
|----------|------|
| `media_kit` + `media_kit_video` + `media_kit_libs_video` | 跨平台视频播放（libmpv） |
| `xterm` + `flutter_pty` | 真终端（xterm UI + 伪终端后端） |
| `webview_windows` | Windows WebView2（爬虫内嵌浏览器） |
| `assets/video/` | 视频资源目录 |
