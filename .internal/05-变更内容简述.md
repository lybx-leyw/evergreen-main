## 三、插件市场（Marketplace）— 新增 + P5 注册

> 3 个 Dart 文件，本地插件管理 + 侧边栏接入。

### 3.1 文件清单

| 文件 | 功能 |
|------|------|
| `marketplace_slot.dart` | 主槽位 — 扫描插件、展示列表、搜索/过滤、启用/停用/卸载 |
| `local_plugin_card.dart` | 插件卡片 UI（名称、描述、开关、侧栏控制、卸载按钮） |
| `marketplace.dart` | barrel export |

### 3.2 关键技术细节

- **路径注入**：`ConsumerStatefulWidget` + `ref.read(pluginsDirProvider)` 三级回退（config > Riverpod > 硬编码）
- **隐藏目录检测**：`p.basename(entity.path).startsWith('.')` + 路径 `p.normalize()`
- **侧边栏注册**：`plugins/marketplace/module/manifest.json` — icon=`store`, route=`/marketplace`, section="系统"

### 3.3 踩坑修复

| 问题 | 根因 | 修复 |
|------|------|------|
| 插件市场未出现在侧边栏 | manifest `preset` 字段误写为 String | 改为 `"type": "fullscreen"` |
| "暂无本地插件" | 硬编码相对路径 `'plugins'` | Riverpod 注入 `pluginsDirProvider` |
| 全部目录被误判为隐藏 | `entity.path.contains(r'\.')` 匹配 `\..\` | `p.basename()` + `p.normalize()` |
