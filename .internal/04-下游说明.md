## 原理

### 1. 下游核心定位

下游是**纯渲染层**。它：
- 接收上游的 `ModuleDescriptor` 和 Riverpod 注入的数据
- 按声明自动选择视图（ModuleDispatch）
- 不解析 manifest.json（那在上游做）
- 不管理进程生命周期（那在上游做）
- 不写业务逻辑
- 只画像素

### 2. 三层渲染结构

```
widgets/ 原子组件          shared/ 范式视图+调度        compositions/ 叠加
─────────────────         ─────────────────────       ─────────────────
纯展示，不放业务逻辑        组合 widgets/ 原子           高级多视图叠加
接收 Options + 数据        处理布局和调度                编排多个范式视图
```

下层不放上层的事：widgets 不知道 shared 存在，shared 不知道 compositions 存在。

### 3. V2 范式调度（ModuleDispatch）

调度逻辑不再是 `descriptor.ui` 的 switch，而是按模块的**实际内容**自动选择：

| 条件 | → 视图 | 说明 |
|------|--------|------|
| `renderMode == "html"` | `HtmlRenderView` | WebView 内嵌 HTML |
| `descriptor.pages` 非空 | `CompositeView` | 多版 Tab + SlotDispatch（53 种组件） |
| `descriptor.workspace.enabled` | `EditorView` | 代码/文本编辑器 |
| 其他 | `DefaultView` | 数据绑定兜底 |

### 4. SlotDispatch——53 种组件映射

`slot_widgets.dart` 是核心调度文件（1387 行），将 JSON 声明的组件类型映射为 Flutter Widget：

- chat / chat-input / ai-assistant → 对话组件
- table / spreadsheet / grid → 表格组件
- code / editor / markdown → 代码/文档编辑
- form / input / select → 表单组件
- calendar / timeline / gantt → 时间组件
- chart / dashboard / stat-tile → 数据可视化
- file-tree / file-viewer / media → 文件操作
- lottery / flashcards / pomodoro → 趣味/学习工具
- button / action-bar / toolbar → 交互组件
- 未知类型 → `_UnknownSlot`（不崩溃，静默降级）

### 5. HTML 渲染引擎

`html/` 目录包含完整 HTML5 离线导出引擎，将 Dart 的声明式 UI 编译为纯 HTML/CSS（不依赖 Flutter），用于：
- 离线分享（导出为 .html 文件）
- WebView 内嵌渲染（renderMode: "html"）
- 浏览器独立运行

### 6. Design Tokens 系统

`render_tokens.dart`（625 行）定义了全平台的 Design Tokens：间距、圆角、阴影、字体、颜色语义 token 等。主题系统从 ThemeDescriptor 解析 token 到 Flutter `ThemeData`。

## 效果

- **声明即 UI**：模块只需 JSON 声明，渲染层自动生成 53 种组件对应的 Flutter Widget
- **容错设计**：未知字段/组件类型静默降级，不抛异常
- **代码模式清晰**：
  - 原子组件：`StatelessWidget` + `Options` + 数据模型
  - 交互组件：`StatefulWidget`（仅 UI 状态，不调 API）
  - 范式视图：组合 widgets/ 原子 + 处理布局和调度
- **Stub 隔离**：11 个 stub 包使渲染层可脱离 Flutter SDK 独立分析
- **多平台自适应**：AppShell 自动判断桌面/移动端布局（800px 阈值）
