## 原理

### 1. 下游核心定位

下游是**纯渲染层**。它：
- 接收上游的 `ModuleDescriptor` 和 Riverpod 注入的数据
- 按声明自动选择视图（`ModuleDispatch`）
- 不解析 manifest.json（那在上游做）
- 不管理进程生命周期（通过 `ProcessManager` 委托上游）
- 不写业务逻辑

### 2. 三层渲染结构

```
widgets/ 原子组件          shared/ 范式视图+调度        compositions/ 叠加
─────────────────         ─────────────────────       ─────────────────
纯展示，不放业务逻辑        组合 widgets/ 原子           高级多视图叠加
接收 Options + 数据        处理布局和调度                编排多个范式视图
```

下层不放上层的事：widgets 不知道 shared 存在，shared 不知道 compositions 存在。

### 3. V2 范式调度（ModuleDispatch）

`module_dispatch.dart` 按模块的**实际内容**自动选择视图：

| 条件 | → 视图 | 说明 |
|------|--------|------|
| `renderMode == "html"` | `HtmlRenderView` | WebView 内嵌 HTML |
| `descriptor.pages` 非空 | `CompositeView` | 多页 Tab + SlotDispatch |
| `descriptor.workspace.enabled` | `EditorView` | 代码/文本编辑器 |
| 其他 | `DefaultView` | 数据绑定兜底（不崩溃） |

### 4. CompositeView 内部结构

```
TabBar + TabBarView
  └── 每页：独立 ProcessManager + PageEventBus
       └── LayoutEngine 包装（drawers → search → zoom → grid）
            └── 5 种布局范式分发
                 ├── grid：多列网格（preset.columns 1-12）
                 ├── flex：Row/Column/Wrap
                 ├── fullscreen：单 slot 填满
                 ├── absolute：Stack + Positioned
                 └── dock：top/bottom/left/right/center
                 └── 每个 slot → SlotDispatch
```

### 5. SlotDispatch——组件类型分发

`composite_view.dart` 中 `SlotDispatch.build()` 按 `ComponentDescriptor.type` 分发 35+ 种组件：

| 分类 | 组件类型 |
|------|---------|
| 智能交互 | `chat`、`ai-assistant`、`form`、`settings`、`data-dashboard`、`code-editor` |
| 数据展示 | `data-table`、`chart`、`stat-tile`、`timeline`、`card-list`、`kanban`、`map`、`tree` |
| 文档媒体 | `document`、`spreadsheet`、`presentation`、`video`、`markdown`、`image-gallery` |
| 创作工具 | `mindmap`、`notepad`、`whiteboard`、`diff-viewer`、`terminal` |
| 学习专用 | `type-check`、`flashcards`、`quiz`、`crossword`、`pronunciation` |
| 交互组件 | `nav-button`、`button`、`timetable`、`divider`、`lottery-wheel`、`calendar` |
| 兜底 | `_UnknownSlot`——未知类型不崩溃，静默降级 |

`slot_widgets.dart` 包含学习专用组件的实现：`TypeCheckSlot`、`FlashcardsSlot`、`MindmapSlot`、`QuizSlot`。

### 6. 快速通道——Dart 下游直接 import core

下游有三条**快速通道**，直接 import core 模块实例化上游能力（HTML 渲染做不到）：

**agent 快速通道**（8 个文件）：
- `shared/chat_controller_view.dart`：主聊天 UI，import `core/agent/agent.dart` + `agent_factory.dart` + `agent_runtime.dart` + `session_manager.dart`，通过 `AgentAssembly.fromConfig()` 实例化 Agent，消费完整 `AgentEvent` 流
- `multi_agent/single_agent_column.dart`：多 Agent 并行列，import `core/agent/agent.dart` + `agent_factory.dart` + `file_memory_store.dart` + `skill.dart`
- `multi_agent/multi_agent_view.dart`：多 Agent 布局外壳，import `core/agent/agent.dart`
- `shared/chat_view.dart`：轻量嵌入聊天视图，import `core/agent/event.dart` + `controller.dart` + `agent_runtime.dart`
- `shared/global_memory_view.dart`：记忆管理，import `core/agent/memory/memory.dart`
- `shared/skill_management_view.dart`：技能管理，import `core/agent/skill/skill.dart`
- `widgets/chat_input_bar.dart`：输入栏，import `core/agent/agent_runtime.dart`
- `widgets/session_list_bar.dart`：会话选择器，import `core/agent/agent.dart` + `session_manager.dart`

**data 快速通道**：
- `shared/data_dashboard_view.dart`：数据中枢面板，import `core/data/data.dart`，直接调用 `DataOrchestrator.get()` / `.refresh()`
- `widgets/freshness_badge.dart`：数据新鲜度徽章，import `core/data/database.dart`，读取 `WebCacheDatabase`

**config 快速通道**：
- `shared/settings_view.dart`：设置表单，import `core/config/settings.dart`，调用 `initSettings()` / `getAllSettings()` / `setSetting()`
- `shared/chat_controller_view.dart`：import `core/config/config.dart`，`getSetting(prefs, 'DEEPSEEK_API_KEY')`

### 7. PageEventBus——跨 Slot 通信

`CompositeView` 为每个页面创建独立的 `PageEventBus`，支持 slot 间无需 Dart 代码的事件通信：
- `slot:toggle:<key>`：切换 slot 可见性
- `slot:switch_page:<pageId>`：编程式切换 Tab 页

### 8. HTML 渲染引擎

`html/` 目录包含完整 HTML5 离线导出引擎，将 manifest JSON 编译为纯 HTML/CSS（不依赖 Flutter），用于：
- WebView 内嵌渲染（`renderMode: "html"`）
- 离线分享（导出为 .html 文件）
- 浏览器独立运行

布局引擎与 Dart 端镜像 5 种范式（`html_layout.dart` 生成对应 CSS）。

## 效果

- **声明即 UI**：模块只需 JSON 声明，渲染层自动生成对应的 Flutter Widget
- **双渲染模式**：dart 完整功能 + html 预览
- **快速通道**：Dart 下游直接 import core，零序列化开销
- **容错设计**：未知字段/组件类型静默降级，不抛异常
- **代码模式清晰**：
  - 原子组件：`StatelessWidget` + `Options` + 数据模型
  - 交互组件：`StatefulWidget`（仅 UI 状态，不调 API）
  - 范式视图：组合 widgets/ 原子 + 处理布局和调度
- **Stub 隔离**：renderer 可脱离 Flutter SDK 独立 `dart analyze`
- **多平台自适应**：`AppShell` 自动判断桌面/移动端布局
