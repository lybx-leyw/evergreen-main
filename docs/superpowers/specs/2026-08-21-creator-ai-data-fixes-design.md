# 插件创作中心、AI Tool 与数据中枢修复设计

## 范围

一次性修复三个相关问题：Android 插件创作中心缺少画板/实例面板且无法新建画板；Agent Tool 空返回导致 AI 提前停止；应用启动时数据中枢不能安全地串行刷新多个数据源。

## 设计

1. 画板与实例：继续复用现有 CanvasManager、InstanceMeta 和会话持久化模型，Android 仅补齐与 Windows 对齐的列表、预览、空状态和新建入口，不引入平台专属状态。
2. Tool 协议：所有 Tool 调用返回统一的结构化结果，成功无数据时也返回明确确认；异常、超时和取消保留错误上下文并标记可继续状态。Runtime 对历史 null/空结果做兼容包装。
3. 数据中枢：应用启动完成后取得已注册数据源，使用单一串行队列按稳定顺序拉取。单个源失败记录状态后继续，启动刷新与手动刷新共享调度锁，避免并发拉取；本阶段不做并行模式。

## 验收

- Android 首次进入创作中心能看到画板空状态并新建画板；已有画板能看到实例展示/预览，增删改后状态持久化。
- 每个 Tool 的成功、空数据、失败、超时、取消路径均不会让 Agent 因空返回自行结束，并有测试覆盖。
- App 启动后数据源按顺序拉取；任一失败不阻塞后续；重复触发不会并发执行；状态和错误可观察。
