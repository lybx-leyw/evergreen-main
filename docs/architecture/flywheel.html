核心原则
registry = 协议声明，不是代码

作者只需声明「插件从哪下载、manifest 从哪来」，Evergreen 自动完成下载与加载；条目经飞轮采集、展示、安装后，greenix 按 module / agent / theme / config / data / skill 采择集成。

用户侧创作以 HTML 为主 —— 创作中心一键导出 module/index.html + manifest.json，立即进入飞轮。
