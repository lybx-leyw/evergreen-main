HTML 插件 · 用户侧主路径

  • 产物：module/index.html + manifest.json（manifest "template":"html"）
  • 创作：html-creator 三栏 IDE · AI 生成 · 一键导出
  • 运行：html_modle 本地 HTTP + WebView + platform.* JS Bridge
  • 主题：--evg-* CSS 变量实时注入；进程：manifest process 白名单（fail-closed）

HTML 插件 JS Bridge 能力表（platform.* · 用户侧主路径）
platform.data

get(name) 缓存优先读取 · list() 数据源清单 · refresh(name) 读缓存 · subscribe(name, fn) 订阅变化（data:changed）· testConnectivity() 连通性测试

platform.ai

chat(prompt, style) → POST /agent/chat（AgentHttpServer）；style 可选 explanatory / learning / concise / socratic

platform.api

call(service, path, {method, body}) → agent / config / data / module / theme / core 六组服务通用转发，端口来自 .xxx_port 端口文件

platform.settings

get(key) 读取 · set(key, value) 写 ConfigHttpServer 并同步 .greenix/config.json

platform.storage

get / set / remove / clear / list → 模块私有 storage.json；同时注册为数据源 <id>_storage

platform.theme

getColors() 返回 8 语义色；--evg-* CSS 变量注入，主题切换实时推送（theme:changed）

platform.process

run / start / write / stop / read / onOutput / onExit → manifest process 白名单 fail-closed；scope:"long" 常驻

platform.emit / platform.on

页级事件：PageEventBus 广播与订阅，同页跨栏 / 模块联动

💡 HTML-first 修正（对照 CLAUDE.md + evg-base 源码）： ① 插件形态 —— 用户侧主路径为 plugins/<id>/module/index.html + manifest.json（"template":"html"），由 html-creator 创作、html_modle（本地 HTTP + WebView + JS Bridge）运行；「JSON 声明 + .exe」已降级为开发者模式 / 高级能力。
② 渲染机制 —— 弃用 renderMode 双渲染表述：ModuleDispatch 按 template / pages / workspace 自动选视图（不再使用 descriptor.ui），经模板注册表路由 v4 / html / scraper / theme-creator / skill-creator / dsh / zju 等。
③ 装配流程 —— main.dart 经 AppBootstrap 25 步启动（详见上方详情卡逐站点亮）。
④ 保留仍正确的核心 —— core/ 纯 Dart 服务层不画像素、renderer/ 只消费 core barrel API、HTTP 端口体系与 JS Bridge 能力表。
