三路 = 同一份插件资源的三种消费视角；开发者模式与底层资源之间的双向箭头 = 创作产物回流到底层资源，平台再次发现并分发
AI 助手视图
AI 统一调度
对话 / 深度思考、agent tool 调用、skill 加载、五维记忆、数据中枢取数——AI 统一编排资源完成用户任务。
插件视图
用户切身体验
市场发现与安装、HTML 模块渲染（template:"html"）、主题与皮肤一键切换——用户直接消费插件能力。
开发者模式视图
AI 与用户审查创作
审查既有插件、用工坊（scraper / html-creator / skill-creator / theme-creator）创作新插件、导出上架——产物回流到底层资源。
🔁 回流闭环：开发者模式创作产物（manifest + 适配壳 + 插件包）写入底层资源层（plugins/、registry）→ 平台自动发现 → 再经前端分发到三路。双向箭头 = 资源供审查创作，创作产物反哺资源。
