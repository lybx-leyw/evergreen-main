## 1. 日志在哪里

| 场景 | 位置 | 说明 |
| --- | --- | --- |
| Debug 模式（桌面/安卓） | stderr（终端 / `adb logcat`） | `Log()` 直接输出，同步不丢 |
| Release 模式（桌面） | `<应用数据目录>/evergreen/logs/evergreen_0..4.log` | 单文件 ≤5MB，轮转保留 5 个 |
| Release 模式（安卓） | logcat | `Log.mirrorToStderr=true` 镜像到 stderr，`adb logcat -s Flutter` 可见 |
| 应用内 | Debug 底部错误中心（DebugErrorBar） | 实时错误列表 + 复制 errorId + 一键导出 200 条 |
| 启动过程 | 日志开头 `[BOOT] N/23 ...` 序列 | grep `[BOOT]` 即得完整启动时间线 |

## 2. 日志行格式

```
[2026-08-02 02:15:47.716] [ERROR] [PluginInstaller] [EVG-a1b2c3d4] 插件安装失败
  data: {...}
  error: FileError: 文件写入失败
  stack: #0 ...
  source: lib/core/services/plugin_installer.dart:123   ← AppError 序列化时附带
```

| 字段 | 含义 |
| --- | --- |
| 时间戳 | `YYYY-MM-DD HH:MM:SS.mmm`（本地时区） |
| 级别 | DEBUG / INFO / WARN / ERROR |
| 模块标签 | 由调用栈提取的类名/文件名（如 `PluginInstaller`、`BOOT`、`log_test`） |
| errorId | `EVG-xxxxxxxx`（Log 生成）或 `EVG-<模块>-xxxxxxxx`（AppError 携带） |

## 3. 错误码表（errorId 前缀）

| 前缀 | 模块 | 典型错误 |
| --- | --- | --- |
| EVG-BOOT | 启动序列 | 步骤失败（`[BOOT] ❌ N/23 <id>`） |
| EVG-CONF | config | 配置缺失/非法 |
| EVG-DATA | data | 解析失败、缓存错误、数据完整性 |
| EVG-MOD | module | 模块加载/生命周期 |
| EVG-AGT | agent | Agent 运行时/工具 |
| EVG-THM | theme | 主题加载 |
| EVG-REND | renderer | 渲染错误、布局溢出 |
| EVG-SVC | services | 网络/认证/超时/AI/文件/未知 |
| EVG-PLG | 插件运行时 | Python/WebView 桥 |

> 无前缀的 `EVG-xxxxxxxx` 为 Log 层按 (模块,消息) 哈希生成；AppError 自带 `EVG-SVC-xxxxxxxx` 等增强格式。

## 4. 排查标准流程（3 分钟定位）

```
1. 找日志      → 见 §1（release 桌面读文件；安卓读 logcat；debug 读终端）
2. 检索        → dart run tool/log_scan.dart --id EVG-xxxxxxxx
               （或 --module PluginInstaller --level ERROR --since 2026-08-01）
3. 定位        → 命中行含 source 字段（文件:行号）与 stack（调用链）
4. 上报        → 错误中心「导出日志」→ 附 errorId + 复现步骤发 Issue
```

### log_scan 速查

```bash
dart run tool/log_scan.dart --id EVG-a1b2c3d4              # 按 errorId
dart run tool/log_scan.dart --module BOOT --ctx 10         # 启动时间线
dart run tool/log_scan.dart --level ERROR --since 2026-08-01 --max 50
dart run tool/log_scan.dart --file <log 文件> --id EVG-xx  # 指定文件
```

## 5. 高频场景速查

| 症状 | 检索方式 | 常见根因 |
| --- | --- | --- |
| 启动到某步失败/降级 | `--module BOOT` | 看 `[BOOT] ❌` 行 + errorId |
| 启动黑屏/白屏 | `--module BOOT`（无 `完成` 行） | 致命步骤 greenix-paths 失败 |
| 界面溢出/渲染异常 | `--level ERROR` + `--module REND` | RenderError，logcat 有 overflow 详情 |
| AI 对话失败 | `--module AGT` 或搜 `AI model error` | ApiKey/限流/模型不可用 |
| 插件安装失败 | `--module PluginInstaller` | 签名/目录权限/网络 |
| 安卓 logcat 无日志 | — | 检查 `Log.mirrorToStderr`（main() 已开启）+ `adb logcat -s Flutter` |
| 日志文件找不到 | — | Windows: `%LOCALAPPDATA%\evergreen\logs\` |
